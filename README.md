# Лабораторна робота 5: Використання SFML в C++ проєкті
**Варіант 19:** Маятник під дією періодичної сили

## Опис проєкту
Програма моделює поведінку математичного маятника під дією сили тяжіння, затухання та зовнішньої періодичної сили. Реалізовано за допомогою C++17, графічної бібліотеки SFML, системи збирання CMake та менеджера пакетів vcpkg.

## Як зібрати та запустити
1. Переконайтеся, що у вас встановлено Visual Studio з компонентами C++ та налаштований `vcpkg`.
2. Відкрийте цю папку через Visual Studio (**File -> Open -> Folder...**).
3. Дочекайтеся завершення конфігурації CMake та автоматичного встановлення SFML через vcpkg.
4. Зберіть проєкт (**Build -> Build All**) та натисніть **F5** для запуску.
